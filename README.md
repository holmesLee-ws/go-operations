# go-operations

생산·운영·품질관리를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 생산계획(MPS·MRP), 용량·스케줄링, 린(TPS), 품질경영(SPC·6시그마·ISO 9001), 설비·보전(OEE·TPM), 현장 안전·환경, 식품 안전(HACCP)을 다룹니다. 국내 법령·고시·KS가 뼈대이고, ISO 표준과 주요국 법제는 비교 축입니다. 제조 현장 중심이며, 현장을 몇 년째 이끌어 왔지만 체계를 세우고 싶은 관리자도 대상입니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다. 계산은 튜터가 만드는 페이지나 평소 쓰는 스프레드시트로 합니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-operations
```

**Claude Code**

```bash
cd ~/Desktop/go-operations
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-operations` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 어떤 현장에서 무슨 일을 하는지 짧게 묻고, 내 일과 가까운 세 영역에서 문제를 하나씩 풀어 출발점을 찾습니다. 현장 경험이 없으면 이 단계는 생략합니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답과 내 현장 숫자를 반영한 HTML을 만들어 가며 익힙니다. 모듈마다 점검표·계획서·기준서처럼 회사에서 쓸 수 있는 초안을 함께 만듭니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기(영역: F·P·L·Q·M·S·D) |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 업무 산출물 초안. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 산출물 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달됩니다. 회사 자료를 붙일 때는 거래처·고객·직원 이름 같은 민감한 정보를 지우고 넣으세요.

## 법령과 표준에 대해

법령·고시·표준은 자주 바뀝니다. 튜터는 조문·의무 대상·시행 시기·기준값을 말할 때 그 자리에서 국가법령정보센터 같은 공식 출처를 확인하고, 확인하지 못하면 그렇다고 말합니다. 여기서 만드는 점검표·계획서는 **교육용 초안**입니다. 실제 사업장에 적용하기 전에 안전·보건 전문가, 인증기관, 노무사·변호사 등 전문가의 확인을 받으세요.
